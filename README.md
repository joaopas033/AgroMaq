AgroMaq
Projeto acadêmico de uma plataforma de anúncios de máquinas agrícolas, desenvolvido para praticar a integração entre frontend, backend e banco de dados.
Tecnologias utilizadas
- Nuxt e Vue
- NestJS
- TypeScript
- PostgreSQL e Prisma
- Tailwind CSS
- Supabase
Funcionalidades
- Cadastro e login de usuários.
- Consulta de anúncios com filtros.
- Criação, edição e exclusão dos próprios anúncios.
- Envio de imagens.
Como executar
Instale as dependências com npm install nas pastas do frontend e do backend. Configure os arquivos .env com a conexão do banco de dados, o Supabase e o endereço da API.
Depois, execute npm run dev em cada pasta, mantendo os dois servidores abertos.
Observações
O projeto está em desenvolvimento. A funcionalidade de favoritos ainda não foi implementada e o endereço da API precisa ser configurado para um servidor disponível.
Os arquivos .env com senhas e chaves de acesso não devem ser publicados no GitHub.
